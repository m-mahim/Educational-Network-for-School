<div align="center"><b>School Campus Networking System</b></div><br>
It is a simulated network design tailored for educational institutions. It integrates subnetting and multiple services such as NAT, DHCP, DNS, HTTP, wireless routing, static routing, and remote access control. The system demonstrates practical campus-level network configuration with segmented access for students, staff, and administration, ensuring secure communication, efficient resource sharing, and controlled connectivity across the campus environment.<br><br>
<b>Tools & Libraries:</b> Cisco Packet Tracer, Cisco IOS CLI, Networking Protocols (NAT, DHCP, DNS, HTTP), Access Control Lists (ACLs), draw.io <br><br>
